# tech-interview-notes

技術面接で答えられなかった / 詰まったトピックを、後で見返せる教材として整理するリポジトリ。

各教材は「サマリ → 本質 → 対比 → ハンズオン → 落とし穴 → Q&A → 模擬面接質問」の構成で書かれている。詳しい運用ルールは [CLAUDE.md](CLAUDE.md) を参照。

## 索引

| トピック | カテゴリ | ファイル |
|---|---|---|
| TCP / UDP の違い | ネットワーク | [docs/tcp-udp.md](docs/tcp-udp.md) |
| INDEX（DB の索引） | データベース | [docs/index.md](docs/index.md) |
| タプル と リスト の違い | Python | [docs/tuple-list.md](docs/tuple-list.md) |

## 使い方

### 普通に読む
`docs/<topic>.md` をそのまま読む。`<details>` で隠れている Q&A の解答は、**自分で答えを口に出してから**開くと効果的。

### 模擬面接モード
Claude Code でこのリポジトリを開いて、次のように頼む:

```
docs/tcp-udp.md の模擬面接やって
```

→ 章末の模擬面接質問を 1 問ずつ出題して、回答を採点してくれる（採点基準は [CLAUDE.md](CLAUDE.md) 参照）。

### 学習モード（穴埋め）
出力スタイルを切り替えて、教材を**自分で埋める**形に変換できる:

```
/output-style learning
docs/index.md を学習モードで作り直して
```

→ 重要な定義やコードの一部に `???` や `TODO(human)` が入った穴埋め版が生成される。

## 新トピックの追加

詰まったトピックに出会ったら:

```
<topic名> の教材を作って
```

→ テンプレに従った教材を生成して、この索引も自動で更新してくれる。
